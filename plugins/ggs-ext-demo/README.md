# GGX Demo

The ggx/2 package format's worked example: one page (`web/view.html`, spoken to through
`acquireGgsApi`), one process backend (`src/main.rs`, the `ggs-ext/1` line-JSON-RPC protocol
over stdin/stdout) and two contributed commands.

Install the `.ggx` from the Extensions view (Install from GGX...), then run
"GGX Demo: Hello" from the command palette, or "GGX Demo: Open the Page".
